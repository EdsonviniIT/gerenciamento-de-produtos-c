
# Gerenciamento de Produtos em C

Sistema desenvolvido em linguagem C para gerenciamento de produtos, com armazenamento e exportação de informações em arquivos CSV.

## Funcionalidades

- Cadastro de produtos
- Consulta de registros
- Alteração e exclusão
- Pesquisa por nome ou categoria
- Ordenação com Bubble Sort
- Armazenamento e exportação em CSV

## Conceitos aplicados

- Structs
- Ponteiros
- Funções
- Manipulação de arquivos (`FILE`, `fopen`, `fgets`, `fprintf`)
- Manipulação de strings (`strcmp`, `strstr`)
- Estruturas de repetição e decisão (`for`, `switch`)
- Algoritmo Bubble Sort

## Tecnologias

- Linguagem C
- Visual Studio Code
- Git e GitHub

## Objetivo

Aplicar conceitos fundamentais da linguagem C na construção de um sistema funcional, desenvolvendo conhecimentos em lógica de programação, organização de dados e manipulação de arquivos.
